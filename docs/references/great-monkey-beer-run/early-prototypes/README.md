# Early prototype references

Provided November 3, 2026 for potential direct use or inspiration. Originals are preserved byte-for-byte. These JPEG concept boards include backgrounds, labels, and multiple illustrations; individual elements need extraction, transparency cleanup, and animation registration before gameplay use.

- `monkey_characters_items_environment_sprites.jpg`: monkey poses and outfits, vehicles, enemies, special characters, collectibles, power-ups, and environment ideas.
- `nana_racer_goat_jungle_truck_sprites.jpg`: white Nana-Racer and black GOAT Jungle Truck poses, vehicle effects, and themed items.
- `unicorn_garage_concepts.jpg`: garage exterior, upgrade garage, bar, upstairs apartment, signs, props, and lighting.

These are optional design resources, not finalized choices for levels, mechanics, characters, vehicles, or the game title. They supplement the existing Phaser export and other reference art.
