# App branding

`app-icon-original.png` is the user-provided provisional app icon, preserved unchanged.

The default Save/Add to Home Screen label must be **Lil G in EC**. When implementing the web app, set both web app manifest `name` and `short_name` to `Lil G in EC`, and the HTML `apple-mobile-web-app-title` meta tag to the same value. Generate platform-sized icons from this original and link them in the manifest and HTML.

The prototype includes these settings and uses 180, 192, and 512 pixel icon variants. The final game title remains TBD.

## Main working logo

`main-logo.png` is the user-designated main working logo for the GitHub README and in-game use. The supplied PNG is preserved unchanged and is embedded in the root README. It takes precedence over the earlier title-logo concept as the current logo. The prototype uses it on the title screen. The home-screen label remains **Lil G in EC**.
